# UserStatus

Готовый пример React-компонента по правилам style guide.

```text
user-status/
├── styles/
│   └── user-status.module.css
├── types/
│   └── user-status-props.type.ts
├── user-status.tsx
└── index.ts
```

Используй пример как форму реализации, а не как готовую domain-сущность. Замени имя, props, HTML-элемент, сценарии документации и стили в соответствии с ответственностью создаваемого компонента.
